# BrightLine website (Netlify)

Files: index.html, thanks.html, favicon.svg, logo.svg. No build step.

1. Put these files at the ROOT of a GitHub repo.
2. Netlify > Add new site > Import from Git > pick the repo.
   Build command: (leave empty)   Publish directory: .
3. After the first deploy: Site configuration > Forms. The "contact" form appears after the first deploy.
   Forms > Form notifications > Add notification > Email notification > mohab.r.2022@gmail.com
4. Domain: Domain management > Add a domain > brightlinesec.com, then follow the DNS steps.
5. Test: submit the form on the live site and check the Forms tab and your inbox.
